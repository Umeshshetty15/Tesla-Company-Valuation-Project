# Tesla-Company-Valuation-Project
Built a fully integrated 3-statement Tesla financial model covering P&amp;L, Balance Sheet and Cash Flow, with a bottoms-up revenue build. Modeled Opex, PP&amp;E, depreciation and working capital with Best/Base/Worst-case scenarios. Calculated CAPM-based WACC and performed DCF valuation to derive Enterprise Value, Equity Value and implied share price.
