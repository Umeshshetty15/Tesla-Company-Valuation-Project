# Tesla-Company-Valuation-Project
• Built an integrated 3-statement financial model for Tesla with bottoms-up revenue forecasting by business segment and vehicle deliveries.
• Modeled Opex, PP&E, depreciation, and working capital using DSO/DIO/DPO with Best/Base/Worst-case scenarios.
• Calculated CAPM-based WACC and performed DCF valuation to derive Enterprise Value, Equity Value, and implied share price.
